# Orchestration Fundamentals for Agentic Development

This is the standalone pre-class setup repository for **Orchestration Fundamentals for Agentic Development**. Use this repository to prepare and validate the tools required for the course before class. Learners need Claude Code, Git, and a terminal environment suitable for inspecting files, creating isolated branches or worktrees, merging changes, and running supplied acceptance checks.
