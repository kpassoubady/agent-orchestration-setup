# Agent Orchestration Setup

Pre-class environment setup for **Orchestration Fundamentals for Agentic
Development**.

Use this repository to prepare and validate the tools required for the course
before class. Learners need Claude Code, Git, and a terminal environment
suitable for inspecting files, creating isolated branches or worktrees,
merging changes, and running supplied acceptance checks.

## Expected Experience

- Prior use of Claude Code or a similar AI coding assistant
- Working knowledge of Git branches and merges
- Comfort inspecting files and running commands in a terminal
